# Reuse-first image release

111 previously empty slots filled: 108 reviewed shared placements and three new source files. Coverage rises from 139 to 250 of 633 slots; 383 remain. There are 84 unique raster files, plus 52 diagrams. Shared placements are not newly generated illustrations.

The three additions are a photograph of a Hegeso relief replica (Sharon Mollerus, CC BY 2.0), the Atlas and Prometheus cup (Commons, CC BY-SA 4.0), and David's 1787 Death of Socrates (Met 436105, CC0). Captions identify the replica and later painting accurately.

`backend/app/course_data/images/shared-images.json` records every shared placement, its source, purpose and review. The original scene request remains in `original_brief`; image alt text describes the actual asset. Shared story pictures are labeled in the learner interface. The admin dashboard exposes both captions and reuse provenance, searchable and exportable to CSV.

Run `python backend/scripts/apply_shared_images.py` to apply reviewed mappings, then `python backend/scripts/build_images.py inventory`. The importer checks all course quiz options before writing, and the museum importer preserves shared mappings. Existing asset URLs are reused, so this release uploads only three new binaries.

## Review decisions

Reviewed contact sheets for the 126 downloaded candidates and 81 published raster files. Many candidate searches returned the wrong subject, so downloaded files have not been bulk-approved. Examples include a horse returned for citizen and unrelated vessels for household episodes. A proposed father/son reuse for `hyios` was excluded because it would duplicate a competing quiz picture. Five generic sailor mappings were excluded from passages specifically about naval vessels and fleets.

## Next releases

Work through the existing curriculum priorities. Reuse reviewed images when the visible subject or lesson setting fits. Source museum photographs for identifiable artifacts, objects and sites. Generate simple illustrations only for unresolved concepts and actions. Aim for 50–100 justified placements per release; preserve distinct picture choices and truthful captions. Original curriculum batch IDs remain useful grouping labels, not eight-image release limits.
